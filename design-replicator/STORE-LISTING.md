# Chrome Web Store kayıt taslağı
Ad: Design Replicator — Binbir Dizayn
Kısa açıklama: Sayfaları HTML/CSS/JS tasarımına dönüştürün. Binbir bileşeni keşfedin; Pro ile sitenize uyarlayın.

Design Replicator, açık sayfanızın statik tasarımını veya bir görseldeki tasarımı düzenlenebilir HTML, CSS ve JavaScript çıktısına dönüştürür.

Ücretsiz araçlar:
- Sayfa klonlama, renk paleti çıkarma ve HTML indirme
- 1001 referans bileşeni keşfetme
- Kod editörü ve canlı önizleme

Ücretli Pro üyelik:
- Binbir Dizayn Uyarla: bileşeni mevcut belgenin seçili alanına uyarlama
- İçeriği tasarıma veya tasarımı mevcut içeriğe uygulama
- AI üretim araçları ve ZIP indirme

Pro, harici ödeme hizmetinde satın alınan abonelik gerektirir. Fiyat, yenileme dönemi ve kullanım hakkı ödeme öncesinde gösterilir. AI sağlayıcılarının API maliyetleri ayrıca uygulanabilir; ChatGPT veya Claude aylık üyeliği API kredisi sağlamaz. Aboneliğinizi Pro alanındaki yönetim portalından iptal edebilirsiniz.

Klonlar sayfanın statik bir kopyasıdır. Sonuçlar AI modeline göre değişebilir. Yalnızca kullanma hakkınız olan içerikleri işleyin.

İzin gerekçeleri:
- activeTab / scripting: kullanıcının başlattığı sayfa yakalama
- storage / unlimitedStorage: ayarlar, bileşen kütüphanesi, yerel proje verisi
- contextMenus: sayfa/görsel sağ tık kısayolu
- declarativeNetRequest: yalnızca yerel model sunucularıyla Origin uyumluluğu
- tüm siteler: harici görsel, font ve CSS indirme; kullanıcının seçtiği sağlayıcıya istek

Yayın engelleri: işletmeci/destek ve gizlilik URL'leri, gerçek fiyat ve kota, mağaza ekran görüntüleri, üretim hizmeti, hesap kurtarma/silme süreci ve canlı ödeme testi tamamlanmalıdır.
